# 10 · 商城与个人中心（MKT）

[← 返回总览](./README.md)

> v1.1-draft 新增模块（2026-10-02）。产品从“独立店铺工具”调整为“商城 + 卖家中心”：平台有统一的商城首页展示所有店铺的商品，一个账号既能买也能卖。资金直连、平台不抽成、店铺品牌页与装修保持不变。

## 1. 模块概述
- 所有人都可以浏览商城首页、搜索商品、查看商品与店铺页。
- 登录用户可以收藏商品，并在个人中心查看收藏和已购订单。
- 任何用户都可以在个人中心主动开店，开店后进入卖家中心上架商品；**开店不再是注册后的强制步骤**。

## 2. 功能清单

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| MKT-01 | 商城首页 | 搜索框、分类入口、热门商品、最新上架 | P0 |
| MKT-02 | 商品搜索 | 关键词搜索，按分类、价格筛选，按综合 / 销量 / 最新 / 价格排序 | P0 |
| MKT-03 | 热门商品 | 按近 7 天成交与收藏计算热度，定时更新 | P0 |
| MKT-04 | 商品分类 | 平台统一的一级分类，商家上架时必选 | P0 |
| MKT-05 | 收藏商品 | 登录后收藏 / 取消收藏，商品显示收藏人数 | P0 |
| MKT-06 | 我的收藏 | 个人中心查看收藏列表，失效商品单独标记 | P0 |
| MKT-07 | 我的订单 | 登录用户查看自己邮箱下的全部订单与交付内容 | P0（依赖订单模块） |
| MKT-08 | 统一账号 | 一个账号同时是买家与卖家；顶栏头像菜单区分个人中心与卖家中心 | P0 |
| MKT-09 | 首页推荐位 | 平台运营在首页置顶推荐商品 | P2 |

## 3. 商品对外展示规则

商品出现在首页、搜索、热门榜和店铺页，需**同时满足**：

| 条件 | 说明 |
|---|---|
| 商品状态为“已上架”（`ON_SALE`） | 上架时自动敏感词审核：通过直接上架；命中进入“待审核”（`PENDING_REVIEW`），由平台人工处理（ADM-04）。被举报的商品由平台人工复查 |
| 店铺不是“已封禁” | 暂停营业的店铺商品仍可浏览，不可购买（PRD 02 3.2） |
| 商品未删除 | — |

> 收款未配置的付费商品不能上架（PRD-08 完整性检查），因此上架商品一定可以购买（店铺暂停营业或库存售罄时除外）。

## 4. 页面与交互

### 4.1 统一顶栏（MKT-08）
所有前台页面（首页、搜索、商品详情、个人中心）共用顶栏：

```
┌──────────────────────────────────────────────────────────┐
│ ◆ MkClou   [🔍 搜索商品、店铺……        ]        登录  注册   │  ← 未登录
│ ◆ MkClou   [🔍 搜索商品、店铺……        ]   ♡ 收藏  (头像▾)   │  ← 已登录
└──────────────────────────────────────────────────────────┘
头像菜单：我的收藏 · 我的订单 · 卖家中心（已开店）/ 我要开店（未开店）· 账号设置 · 退出登录
```
- 店铺页 `/s/{slug}` 与商品详情页保留店铺自己的品牌顶栏（PRD 06），不使用商城顶栏，避免冲淡店铺品牌感。

### 4.2 商城首页 `/`（MKT-01）
```
┌──────────────────────────────────────────────────────────┐
│ 顶栏                                                       │
├──────────────────────────────────────────────────────────┤
│ 一句话标语 + 大搜索框                                        │
│ 分类入口：全部 · 设计素材 · 软件工具 · 教程课程 · 模板 · …     │
├──────────────────────────────────────────────────────────┤
│ 热门商品                                       [查看更多 →] │
│ ┌────┐ ┌────┐ ┌────┐ ┌────┐                               │
│ │封面 │ │封面 │ │封面 │ │封面 │   商品卡片：封面、名称、价格、    │
│ │名称 │ │名称 │ │名称 │ │名称 │   店铺名、收藏按钮             │
│ └────┘ └────┘ └────┘ └────┘                               │
├──────────────────────────────────────────────────────────┤
│ 最新上架（网格，滚动加载）                                    │
├──────────────────────────────────────────────────────────┤
│ 开店引导横幅：“你也有作品可以卖？几分钟开一家店 [我要开店]”     │
└──────────────────────────────────────────────────────────┘
```
- 未登录也能访问，页面服务端渲染，便于分享和搜索引擎收录。
- 网格：桌面 4 列 → 平板 3 列 → 手机 2 列。卡片封面统一 4:3（商城页不使用店铺各自的卡片比例）。
- 空状态（平台还没有商品）：“商城正在上新，成为第一批卖家 [我要开店]”。

### 4.3 搜索结果 `/search?q=&category=&sort=`（MKT-02）
- 关键词匹配：商品名称、一句话卖点、店铺名称；不区分大小写；关键词 ≤ 50 字符。
- 筛选：分类、价格（全部 / 免费 / ¥0～50 / ¥50～200 / ¥200 以上）。
- 排序：综合（默认，关键词相关度 + 热度）、销量、最新上架、价格从低到高、价格从高到低。
- 分页：每页 24 个，页码分页（方便分享链接与返回时定位）。
- 空状态：“没有找到“xx”相关的商品，换个关键词试试” + 热门商品推荐。
- 不填关键词时等同于“全部商品”列表，可按分类浏览。

### 4.4 热门商品（MKT-03）
- 热度 = 近 7 天成交订单数 × 3 + 近 7 天新增收藏数。成交不计测试订单和已全额退款订单。
- 异步任务每小时计算一次，结果写入 Redis 有序集合，首页读取前 8 个。
- 热度相同按上架时间倒序；热门数量不足 8 个时，用最新上架补齐。

### 4.5 商品分类（MKT-04）
固定一级分类，维护在系统配置中，V1.1 不开放商家自定义：

| 标识 | 名称 | 示例 |
|---|---|---|
| `design` | 设计素材 | 模板、图标、字体、插画、预设 |
| `software` | 软件工具 | 小工具、插件、源码、授权码 |
| `course` | 教程课程 | 电子书、课程、笔记、资料包 |
| `template` | 效率模板 | Notion / Obsidian 模板、表格、提示词包 |
| `membership` | 会员兑换 | 会员、兑换码、点卡 |
| `other` | 其他 | — |

- 商家新建商品时必选，默认无（未选择时不能上架）。

### 4.6 收藏（MKT-05、MKT-06）
- 商品卡片右上角与商品详情页显示收藏按钮（心形图标 + 收藏人数）。
- 未登录点击收藏：跳转登录页，登录后回到原页面并自动完成收藏。
- 同一账号对同一商品只能收藏一次；再次点击取消收藏，乐观更新界面，失败时回滚并提示。
- 我的收藏 `/me/favorites`：按收藏时间倒序，每页 24 个。商品已下架、被平台下架或删除时，卡片置灰并标注“已失效”，提供“移除”按钮；售罄的商品标注“已售罄”。
- 每个账号最多收藏 1000 个商品，超出时提示“收藏已达上限，请先整理收藏夹”。

### 4.7 个人中心（MKT-07、MKT-08）
| 路由 | 页面 | 说明 |
|---|---|---|
| `/me/favorites` | 我的收藏 | 见 4.6 |
| `/me/orders` | 我的订单 | 订单模块完成后实现：展示用该账号邮箱下单的所有订单，点击进入订单交付页 |
| `/me/account` | 账号设置 | 昵称、修改密码、登录设备（接口已有，AUTH-07） |

- 个人中心左侧导航（手机端为顶部 Tab）：我的收藏、我的订单、账号设置；未开店时底部显示“我要开店”卡片。

### 4.8 登录、注册与开店入口（对 PRD 01、02 的调整）
| 场景 | 调整前 | 调整后 |
|---|---|---|
| 注册成功 | 跳转创建店铺向导 | 跳转来源页；无来源页时进入商城首页 |
| 登录成功 | 默认进入 `/dashboard` | 默认进入商城首页 `/` |
| 未开店访问卖家中心 | 强制跳转开店向导 | 显示“开一家你的店”引导页，点击后进入开店向导 |
| 开店入口 | 注册后自动进入 | 顶栏头像菜单“我要开店”、首页开店横幅、个人中心卡片 |

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 搜索关键词含特殊字符 | 去除全文检索运算符后再查询；结果为空时正常显示空状态 |
| 收藏的商品被删除 | 收藏记录保留，列表中显示“已失效”，可移除 |
| 店铺被封禁 | 该店铺商品从首页、搜索、热门中移除；收藏列表中显示“已失效” |
| 热门计算任务失败 | 继续使用上一次的结果；Redis 中无结果时首页热门区用最新上架代替 |
| 未登录收藏后登录失败或放弃 | 不收藏，不留痕迹 |

## 6. 验收标准
- [ ] 未登录可浏览首页、搜索、商品详情；点击收藏跳转登录，登录后自动完成收藏并回到原页面。
- [ ] 登录与注册成功后默认进入商城首页；未开店用户在头像菜单看到“我要开店”。
- [ ] 上架的商品出现在首页“最新上架”与搜索结果中；下架、待审核、店铺被封禁的商品不出现。
- [ ] 搜索中文关键词（如“模板”）能匹配商品名称与卖点；按价格排序结果正确。
- [ ] 收藏与取消收藏后，收藏人数与“我的收藏”列表同步更新。
