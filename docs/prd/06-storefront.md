# 06 · 买家端页面（SF）

[← 返回总览](./README.md)

## 1. 模块概述
买家看到的所有页面：店铺首页、商品详情、结账、支付结果。目标是**让买家在最短路径内完成购买**，同时让店铺看起来专业、有品牌感。设计遵循[设计规范](../design-system.md)场景 B，页面结构参考[竞品页面分析](../competitor-ui-analysis.md)第 5 节。

**全局要求**
- 移动端优先：预计 70% 以上流量来自微信、小红书等移动端分享。
- 首屏性能：LCP < 2.5 秒（4G 网络），店铺页和商品页使用服务端渲染（SSR）。
- SEO：每个店铺页和商品页都有独立的标题、描述和分享卡片（Open Graph），微信分享显示封面图。
- 店铺主题色、明暗模式、卡片比例按商家装修配置渲染。
- 沙箱模式店铺：所有页面顶部显示 warning 横幅“测试模式：付款不会产生真实扣费”。

## 3. 页面与交互

### 3.1 店铺首页 `/s/{slug}`（SF-01）
参考爱发电创作者主页，但**首屏直接展示商品**，而不是动态信息流。

```
桌面端（最大宽度 1080px）
┌───────────────────────────────────────────┐
│           封面横幅（可选，3:1）               │
├───────────────────────────────────────────┤
│ (头像) 店铺名                    [分享] [已购]  │
│        店铺简介                               │
│        🔗 社交链接图标                         │
├───────────────────────────────────────────┤
│ 全部商品 (12)                                │
│ ┌──────┐ ┌──────┐ ┌──────┐                │
│ │ 封面  │ │ 封面  │ │ 封面  │                │
│ │      │ │      │ │ 售罄  │                │
│ │商品名  │ │商品名  │ │商品名  │                │
│ │¥29.90 │ │免费   │ │¥9.90  │                │
│ └──────┘ └──────┘ └──────┘                │
├───────────────────────────────────────────┤
│ 页脚：举报 · Powered by MkClou                │
└───────────────────────────────────────────┘
移动端：头像与店铺名居中，商品网格 1 列（网格模板）或紧凑列表
```

**商品卡片**（设计规范 8.4）
- 封面（店铺统一比例）、商品名（最多 2 行）、价格（有原价时显示划线价）。
- 角标：“免费”“售罄”“新品”（上架 7 天内）。
- 整卡可点击；hover：图片放大 1.03 倍 + 卡片上移 2px。
- 商品按商家设定顺序排列；超过 24 个时滚动加载。

### 3.2 商品详情页 `/s/{slug}/p/{productId}`（SF-02）
参考 Gumroad，但改进为**首屏即可看到价格和购买按钮**。

```
桌面端
┌───────────────────────────────────────────────┐
│ ← 店铺名                                         │
├─────────────────────────────┬─────────────────┤
│                             │ 商品名（h1）         │
│     封面图轮播（60%）          │ 一句话卖点           │
│     缩略图导航                 │ ¥ 29.90  ¥39.90   │
│                             │ 交付方式：文件 · 3 个  │
│                             │ 库存：仅剩 5 件（≤10 时）│
│                             │ 数量 [- 1 +]（卡密）   │
│                             │ [ 立即购买 ]（lg 全宽） │
│                             │ 已经买过？获取商品 →    │
│                             │ ✓ 付款后自动交付        │
│                             │ ✓ 资金直达店主         │
├─────────────────────────────┴─────────────────┤
│ 商品介绍（Markdown 渲染）                           │
│ 包含内容（带图标的清单）                              │
│ 适合谁                                           │
│ 常见问题（折叠面板）                                 │
│ 购买须知                                          │
│ 店主信息卡片：头像 + 店铺名 + 简介 + [查看店铺]        │
│ 店铺其他商品（最多 3 个）                            │
└───────────────────────────────────────────────┘
```

**交互**
- 滚动超过购买按钮后，顶部出现**吸顶购买条**（商品名 + 价格 + 购买按钮）；移动端为底部固定购买栏。
- 封面图点击放大查看，支持左右滑动。
- 购买按钮状态：

| 条件 | 按钮 |
|---|---|
| 正常 | “立即购买” / 免费商品“免费领取” |
| 已售罄 | 禁用，“已售罄” |
| 店铺暂停营业 | 禁用，“店铺暂停营业”，下方显示商家说明 |
| 收款失效 | 禁用，“暂时无法购买” |
| 预览模式 | 禁用，“预览模式” |

- 商品已下架或被平台下架：显示“商品已下架”页面 + “看看店铺其他商品”。

### 3.3 结账页 `/checkout/{productId}`（SF-03）
**原则**：单页、字段最少、不需要注册。参考 Gumroad 结账页，去掉国家、邮编等国内用不到的字段。

```
桌面端（两栏）                                移动端（单列，订单摘要可折叠置顶）
┌──────────────────────┬───────────────┐
│ ← 返回商品              │ 订单摘要         │
│ 联系邮箱 *               │ 封面 商品名       │
│ [ you@example.com ]    │ 单价 ¥29.90     │
│ 用于接收商品，请仔细核对    │ 数量 × 1        │
│ 确认邮箱 *（移动端省略）    │ ───────────    │
│ [                    ] │ 合计 ¥29.90     │
│ 支付方式                │               │
│ (●) 支付宝               │               │
│ □ 我已阅读并同意购买须知    │               │
│ [ 支付宝支付 ¥29.90 ]    │               │
│ 🔒 资金直接支付给店主       │               │
└──────────────────────┴───────────────┘
```

| 字段 | 必填 | 规则 |
|---|---|---|
| 联系邮箱 | 是 | 合法邮箱；常见域名拼写纠错提示（如 `qq.con` → “你是不是想输入 qq.com？”） |
| 确认邮箱 | 桌面端是 | 与邮箱一致；**禁止粘贴**以确保核对 |
| 同意购买须知 | 商品设置了购买须知时必填 | — |

**交互**
- 邮箱保存在本地（localStorage），下次购买自动填充。
- 点击支付：按钮 loading“正在创建订单…”→ 创建订单成功后跳转支付宝。
- 电脑端打开支付宝电脑网站支付页；手机浏览器唤起支付宝 App（手机网站支付）。
- **微信内打开**：支付宝无法在微信内支付，显示遮罩引导“点击右上角 ··· 选择在浏览器中打开”。
- 存在同商品未支付订单时，顶部提示“你有一个未完成的订单 [继续支付]”。
- 免费商品：按钮文案“免费领取”，提交后直接跳转交付页。

### 3.4 支付结果页 `/pay/result?orderNo=`（SF-04）
支付宝同步跳转回来的页面，**不以跳转参数作为支付成功依据**，一律以服务端订单状态为准。

- 订单令牌**不传给支付宝**（避免出现在第三方的跳转地址中）。创建订单时，前端把 `orderNo → 令牌` 保存在本地（localStorage，24 小时后清除），回到结果页时读取令牌查询状态。
- 本地找不到令牌（例如手机上从支付宝 App 返回到另一个浏览器）：显示“支付结果将发送到你的邮箱，也可以通过 [已购查询] 查看”。

| 状态 | 表现 |
|---|---|
| 查询中（≤ 30 秒） | 加载动画 + “正在确认支付结果…” |
| 已支付 / 已完成 | 自动跳转订单交付页 |
| 仍为待支付（30 秒后） | “暂未查询到支付结果。如果你已完成付款，请稍候刷新，结果也会发送到你的邮箱” + [刷新] [继续支付] |
| 已关闭 | “订单已超时关闭，如已付款，款项将自动处理” + [重新购买] |
| 订单不存在 | 404 |

## 4. 埋点与统计（SF-06）
| 事件 | 触发 | 属性 |
|---|---|---|
| `shop_view` | 店铺首页曝光 | shopId、来源、UTM |
| `product_view` | 商品详情曝光 | productId、来源、UTM |
| `checkout_start` | 进入结账页 | productId |
| `order_create` | 订单创建成功 | orderNo、金额 |
| `order_paid` | 支付成功（服务端） | orderNo、金额 |

- UV 以匿名访客 ID（首方 Cookie，1 年）计算，不收集个人信息。
- 来源解析：Referer 域名归类为“微信 / 小红书 / B 站 / 搜索引擎 / 直接访问 / 其他”。
- 用于商家后台转化漏斗：访问 → 进入结账 → 下单 → 支付。

## 5. 异常与边界

| 场景 | 处理 |
|---|---|
| 商品图片加载失败 | 显示 `--muted` 底色占位 + 图片图标 |
| 商家 Markdown 中含有恶意脚本 | 白名单渲染过滤（SEC-05），不执行任何脚本 |
| 访问不存在的店铺或商品 | 404 页面，提供“返回 MkClou 首页” |
| 结账过程中商品售罄 | 提交时返回售罄，结账页显示“刚刚被抢完了”并禁用按钮 |
| 买家在支付宝页面停留超过 15 分钟 | 订单已关闭；支付宝侧交易已关闭，买家无法付款，返回后显示已关闭 |
| 慢网络 | 骨架屏；图片渐进加载；按钮在 JS 加载完成前保持可提交（渐进增强） |

## 6. 验收标准
- [ ] 手机上从店铺首页到完成支付，不超过 4 步操作。
- [ ] 商品详情页首屏（1440×900 与 375×812）可同时看到价格和购买按钮。
- [ ] 微信内打开结账页，出现“在浏览器中打开”引导。
- [ ] 店铺装修配置（主题色、卡片比例、深色模式）在所有买家页面生效。
- [ ] 分享商品链接到微信，显示封面、标题和描述。
- [ ] Lighthouse 移动端性能评分 ≥ 90。
