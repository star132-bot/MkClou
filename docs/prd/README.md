## 2. 版本范围

### 2.1 V1.0 核心闭环
```
商家注册 → 创建店铺 → 配置收款 → 上架商品 → 分享链接
      → 买家浏览 → 填写邮箱下单 → 支付宝支付 → 自动交付 → 邮件通知
      → 商家查看订单与数据 → （必要时）退款
```

### 2.2 不在 V1.0 范围内
- 实物商品、购物车（一次只买一个商品）
- 微信支付（V2）
- License Key、优惠码、捆绑、追加销售、Webhook、PDF 水印（V1.1）
- 会员订阅、分销、AI 功能、自定义域名（V2）
- 平台订阅收费（V1.1，V1.0 所有商家免费使用全部 V1.0 功能）
- 移动端 App（只做响应式网页）

## 3. 用户角色与权限

| 角色 | 身份方式 | 可访问 |
|---|---|---|
| 访客 / 买家 | 无需注册；以**邮箱**作为身份标识 | 店铺页、商品页、结账、订单交付页（凭订单令牌）、已购查询（凭邮箱验证码） |
| 商家 | 邮箱 + 密码注册登录 | 商家后台：自己店铺的所有数据 |
| 平台管理员 | 后台账号（不开放注册，由系统初始化） | 平台管理后台 |

**数据隔离原则**：商家只能读写 `shop_id` 属于自己的数据；任何接口都必须在服务端校验归属，不能信任前端传入的 ID。

## 5. 全局规则

### 5.1 金额
- 币种：人民币，V1.0 不支持其他币种。
- 存储：以**分**为单位的整数，禁止使用浮点数。
- 展示：`¥ 29.90`；整数价格也保留两位小数；0 元显示为“免费”。
- 价格范围：0 元，或 ¥0.01 ～ ¥50,000.00。

### 5.2 时间
- 服务端统一存储 UTC，前端按 `Asia/Shanghai` 展示。
- 24 小时内显示相对时间（“3 分钟前”），超过显示 `2026-10-01 18:04`。

### 5.3 编号
- 订单号：`MK` + 年月日 + 10 位雪花算法尾号，例如 `MK20261001` + `3842917465`，对外展示，不暴露业务量。
- 内部 ID：自增主键，**不在 URL 中暴露**；商品对外 ID 使用 12 位随机短 ID（例如 `p_7Hk2Qa9xLm3c`）。

### 5.4 文本输入
- 所有输入去除首尾空格后再校验。
- 长度按字符计算（一个汉字算 1 个字符）。
- 用户输入内容展示时一律转义；Markdown 渲染使用白名单（见 SEC-05）。

### 5.5 邮件
- 发件人：`MkClou <no-reply@域名>`；交付类邮件发件人名称使用店铺名，例如 `某某的小店 via MkClou`。
- 邮件发送异步执行，失败自动重试 3 次（间隔 1 分钟、5 分钟、30 分钟）。

## 6. 通用交互状态

所有页面和组件必须实现以下状态，样式遵循[设计规范](../design-system.md)第 9 节。

| 状态 | 规则 |
|---|---|
| 加载中 | 首次加载使用骨架屏；局部刷新使用按钮 loading 或局部骨架；超过 10 秒提示“加载较慢，请稍候” |
| 空状态 | 图标 + 一句说明 + 引导操作 |
| 错误 | 说明原因 + 可执行操作（重试 / 返回 / 联系） |
| 提交中 | 按钮 loading 并禁用，防止重复提交 |
| 成功 | Toast 提示，或跳转到结果页 |
| 未保存离开 | 表单有修改时离开页面，弹出确认“有未保存的修改，确定离开吗？” |

## 7. 通用异常处理

| 场景 | 前端表现 | 后端行为 |
|---|---|---|
| 网络断开 / 请求超时（15 秒） | Toast“网络连接异常，请检查网络后重试”，保留已填写内容 | — |
| 400 参数错误 | 字段下方显示具体错误 | 返回字段级错误信息 |
| 401 未登录 / 登录过期 | 自动用 Refresh Token 续期一次；续期失败则跳转登录页，登录后回到原页面 | — |
| 403 无权限 | 显示“无权访问”页面 + 返回入口 | 记录日志 |
| 404 资源不存在 | 显示 404 页面（买家端提供“返回店铺”按钮） | — |
| 409 状态冲突（如订单已被处理） | Toast 说明当前最新状态，并刷新数据 | — |
| 429 请求过于频繁 | Toast“操作太频繁，请 N 秒后再试” | 返回 `Retry-After` |
| 500 服务器错误 | Toast“服务异常，请稍后重试”，附错误追踪号 | 记录错误日志与追踪号 |
| 维护中 | 全站横幅提示 | 配置开关 |

### 7.1 统一响应格式
```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "traceId": "b3f1c2…"
}
```
- `code = 0` 表示成功；非 0 为业务错误码，前端按错误码映射文案。
- 字段校验错误在 `data.fields` 中返回：`{ "email": "邮箱格式不正确" }`。

## 8. 术语表

| 术语 | 说明 |
|---|---|
| 交付 | 买家支付成功后，系统向买家提供商品内容的过程 |
| 交付类型 | 文件 / 卡密 / 链接 / 文本（V1.1 新增授权码） |
| 卡密 | 预先导入的一组唯一字符串（兑换码、激活码等），每单分配一个或多个 |
| 预占 | 下单时锁定卡密库存，支付超时后释放 |
| 订单令牌 | 每个订单生成的随机字符串，用于免登录访问订单交付页 |
| 资金直连 | 买家付款直接进入商家自己的支付宝账户，平台不经手 |
| 幂等 | 同一请求重复执行多次，结果与执行一次相同 |
