# 07 · 商家后台（DSB）

[← 返回总览](./README.md)

## 1. 模块概述
商家后台的整体框架、概览页和数据统计。商品、订单、店铺、收款等具体页面分别见对应模块文档。设计遵循[设计规范](../design-system.md)场景 C：效率优先、克制、信息清晰。

## 2. 功能清单

| 编号 | 功能 | 描述 | 优先级 |
|---|---|---|---|
| DSB-01 | 概览页 | 新手清单、核心指标、待办事项、最近订单 | P0 |
| DSB-02 | 后台框架 | 侧边导航、顶栏、响应式 | P0 |
| DSB-03 | 销售统计 | 营收与订单趋势图、商品排行 | P1 |
| DSB-04 | 转化漏斗 | 访问 → 结账 → 下单 → 支付 | P1 |
| DSB-05 | 来源分析 | 按来源渠道、UTM 统计 | P1 |
| DSB-06 | 全局搜索 | 搜索订单号、买家邮箱、商品 | P1 |
| DSB-07 | 通知设置 | 开关可关闭的邮件通知 | P1 |
| DSB-08 | 快捷键 | `/` 搜索，`N` 新建商品 | P2 |

│ ▤ 数据      │                                          │
│ ─────────  │                                          │

- 侧边栏宽 240px，可折叠为 64px（只显示图标，hover 显示提示），折叠状态记忆在本地。
- 导航角标：订单显示“交付异常”数量，售后显示“待处理”数量。
- 头像菜单：账号设置、帮助文档、退出登录。
- “查看店铺”在新标签页打开 `/s/{slug}`。
- 移动端（< 768px）：侧边栏变为抽屉，顶栏左侧显示菜单按钮。商家后台以桌面端为主，移动端保证核心功能可用（查看订单、退款、上下架）。

## 4. 概览页 `/dashboard`（DSB-01）

```
┌───────────────────────────────────────────────────┐
│ 早上好，阿杰                          [今天 ▾] [新建商品] │
├───────────────────────────────────────────────────┤
│ 新手清单 ●●○○ 2/4（全部完成后可收起）                    │
├───────────────────────────────────────────────────┤
│ ┌销售额────┐ ┌订单数────┐ ┌访客数────┐ ┌转化率────┐     │
│ │¥ 1,280.00│ │ 42       │ │ 1,024    │ │ 4.1%     │     │
│ │↑ 12% 较昨日│ │↑ 5%      │ │↓ 3%      │ │—         │     │
│ └─────────┘ └─────────┘ └─────────┘ └─────────┘     │
├────────────────────────────┬──────────────────────┤
│ 销售趋势（近 7 / 30 天折线图）     │ 待办事项                  │
│                            │ ● 2 个订单交付异常 →        │
│                            │ ● 1 个售后待处理 →          │
│                            │ ● 「xx 兑换码」库存仅剩 3 →   │
├────────────────────────────┴──────────────────────┤
│ 最近订单（5 条）                              [查看全部] │
└───────────────────────────────────────────────────┘
```

**指标定义**
| 指标 | 计算口径 |
|---|---|
| 销售额 | 时间段内**支付成功**订单的实付金额之和，减去同期退款金额；不含测试订单 |
| 订单数 | 时间段内支付成功的订单数 |
| 访客数 | 店铺页 + 商品页的 UV |
| 转化率 | 支付成功订单数 / 访客数 |
| 环比 | 与上一个等长时间段比较；上一期为 0 时显示“—” |

- 时间范围：今天、昨天、近 7 天、近 30 天、自定义（最长 1 年）。
- 指标数据缓存 5 分钟（Redis），页面显示“数据更新于 10:05”。
- 空状态（新店铺）：指标显示 0，趋势图显示占位插图“完成第一笔订单后，这里会显示销售趋势”。

## 5. 数据页 `/dashboard/analytics`（DSB-03 ～ DSB-05）
- **趋势**：销售额 / 订单数 / 访客数切换，按日聚合。
- **商品排行**：按销售额排序，显示商品、访问、订单、销售额、转化率。
- **转化漏斗**：访问 → 进入结账 → 创建订单 → 支付成功，每步显示人数与流失率。
- **来源**：微信、小红书、B 站、搜索引擎、直接访问、UTM 自定义来源，各自的访问量与订单数。
- 图表遵循 dataviz 规范：单一品牌色系、坐标轴简洁、悬停显示精确数值。

## 6. 异常与边界

| 场景 | 处理 |
|---|---|
| 统计查询超时 | 卡片内显示“数据加载失败 [重试]”，不影响页面其他区域 |
| 跨时区 | 统计按北京时间自然日聚合 |
| 订单退款发生在不同统计周期 | 退款计入**退款发生日**，原支付日数据不变 |
| 商家在多个标签页操作 | 列表页切回时自动刷新数据（visibilitychange） |

## 7. 验收标准
- [ ] 新商家首次进入概览，看到新手清单和空状态。
- [ ] 完成一笔测试订单后，指标与趋势在 5 分钟内更新，测试订单不计入。
- [ ] 存在交付异常订单时，侧边导航和待办事项显示提醒，点击跳转筛选后的订单列表。
- [ ] 侧边栏折叠状态刷新后保持。
- [ ] 移动端可以查看订单并完成退款操作。
