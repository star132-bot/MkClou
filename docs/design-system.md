# MkClou 设计规范（Design System）

> 本文档是所有页面 UI 的唯一依据。AI 或人工开发任何页面前，必须先阅读并遵守本规范。
> 新规则请追加到对应章节，并在文末「变更记录」登记。

- 当前版本：v0.3
- 技术基础：Tailwind CSS 4 + shadcn/ui（Radix，Nova 预设）+ Motion + Lucide Icons
- 代码实现：Token 定义在 `web/src/app/globals.css`，修改时两边同步

---

## 1. 设计理念

**关键词：克制、清晰、有质感。**

1. **少即是多**：每个页面只有一个视觉焦点，每个区块只有一个主操作。
2. **一致性优先**：只使用本规范定义的颜色、字号、间距、圆角和阴影，不临时发明新值。
3. **内容为主角**：商品图片和文字是主角，UI 装饰退到背景。
4. **细节体现品质**：hover、focus、loading、空状态、错误状态都要设计，不允许出现“裸”状态。

---

## 2. 场景分级

不同页面的设计自由度不同：

| 场景 | 页面 | 自由度 | 参考 |
|---|---|---|---|
| A. 营销 | 平台官网、落地页、定价页 | 高：可用大字号排版、滚动动画、视差 | Awwwards、FWA、Godly、Linear 官网、Vercel 官网 |
| B. 店铺 | 买家店铺首页、商品详情、结算、购买成功 | 中：以转化为目标，动效轻量 | Gumroad、Lemon Squeezy、Apple Store |
| C. 后台 | 商家后台、平台管理后台 | 低：效率优先，信息密度适中，几乎无装饰动效 | Linear、Vercel Dashboard、Stripe Dashboard |

> 场景 A 的“炫技”效果（3D、WebGL、大面积动画）**禁止**出现在场景 B、C。

## 3. 颜色

所有颜色以 CSS 变量定义（见 `globals.css`），代码中**禁止写死十六进制色值**，只能用语义化变量或 Tailwind 映射类名。

### 3.1 中性色（承担 90% 的界面）

| Token | 亮色模式 | 暗色模式 | 用途 |
|---|---|---|---|
| `--background` | `#FFFFFF` | `#0A0A0B` | 页面背景 |
| `--surface` | `#FAFAFA` | `#111113` | 次级区块背景、侧边栏 |
| `--muted` | `#F4F4F5` | `#1A1A1D` | 输入框底色、hover 底色、标签底色 |
| `--border` | `#E4E4E7` | `#27272A` | 边框、分割线 |
| `--text-primary` | `#09090B` | `#FAFAFA` | 标题、重要文字 |
| `--text-secondary` | `#52525B` | `#A1A1AA` | 正文 |
| `--text-tertiary` | `#71717A` | `#8B8B94` | 辅助说明、占位符、时间（对比度 ≥ 4.5:1） |

### 3.2 品牌色（只用一个）

| Token | 值 | 用途 |
|---|---|---|
| `--brand` | `#5B5BD6` | 链接、选中状态、焦点环、少量强调 |
| `--brand-foreground` | `#FFFFFF` | 品牌色上的文字 |

> **主按钮使用 `--text-primary`（近黑色）而非品牌色**，这是 Linear / Vercel 风格高级感的关键。品牌色只做点缀，单屏面积不超过 5%。

### 3.3 功能色（只用于状态反馈）

| Token | 亮色模式 | 暗色模式 | 用途 |
|---|---|---|---|
| `--success` | `#157238` | `#4ADE80` | 支付成功、已交付 |
| `--warning` | `#A3480A` | `#FBBF24` | 待处理、即将到期 |
| `--danger` | `#C81E1E` | `#F87171` | 错误、删除、退款 |
| `--info` | `#1D4ED8` | `#60A5FA` | 提示信息 |

功能色用于背景时，使用 10% 透明度底色 + 原色文字，例如 `bg-success/10 text-success`。亮色模式下的取值保证文字在白底和 10% 同色底上对比度均 ≥ 4.5:1（第 13 节）。

## 4. 字体

### 4.1 字体族

```css
--font-sans: "Geist", "PingFang SC", "HarmonyOS Sans SC", "MiSans", "Microsoft YaHei", system-ui, sans-serif;
--font-mono: "Geist Mono", "SF Mono", Consolas, monospace;
```

- 英文和数字使用 **Geist**（通过 `geist` npm 包本地加载，不依赖 Google Fonts，避免国内构建失败）；中文使用系统字体，不加载中文网络字体（体积过大）。
- 英文和数字价格、统计数字开启等宽数字：`font-variant-numeric: tabular-nums`（Tailwind：`tabular-nums`）。
- 卡密、订单号、API Key 使用等宽字体。

### 4.2 字号（只允许以下 8 档）

| Token | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 56 / 64 | 600 | 仅限场景 A 主标题 |
| `h1` | 32 / 40 | 600 | 页面标题 |
| `h2` | 24 / 32 | 600 | 区块标题 |
| `h3` | 18 / 28 | 600 | 卡片标题 |
| `body-lg` | 16 / 26 | 400 | 商品描述、长文本 |
| `body` | 14 / 22 | 400 | 默认正文、表单、表格 |
| `caption` | 12 / 18 | 400 | 辅助说明、标签 |
| `price` | 28 / 36 | 600 | 商品详情页价格 |

规则：
- 字重只用 400、500、600 三档，**禁止 700 及以上**。
- 大标题（≥ 24px）使用负字间距 `tracking-tight`（-0.02em）。
- 层级靠**字号 + 字重 + 中性色深浅**区分，不靠彩色。

---

## 5. 间距

只使用 4 的倍数：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128`（px）。

| 场景 | 取值 |
|---|---|
| 图标与文字间距 | 8 |
| 表单项之间 | 16～20 |
| 卡片内边距 | 24（后台）/ 32（店铺） |
| 卡片之间 | 16（后台）/ 24（店铺） |
| 区块之间 | 48（后台）/ 96～128（营销页） |

> 拿不准时，**选更大的那一档**。

---

## 6. 圆角、边框与阴影

### 6.1 圆角

| Token | 值 | 用途 |
|---|---|---|
| `radius-sm` | 6px | 标签、小按钮、复选框 |
| `radius-md` | 8px | 按钮、输入框 |
| `radius-lg` | 12px | 卡片、图片、弹窗 |
| `radius-full` | 9999px | 头像、徽标 |

### 6.2 边框
- 默认 1px `--border`。
- **优先用边框区分层级，而不是阴影。**

### 6.3 阴影（只有 3 种）

| Token | 值 | 用途 |
|---|---|---|
| `shadow-sm` | `0 1px 2px rgba(0,0,0,0.04)` | 卡片 hover |
| `shadow-md` | `0 4px 16px rgba(0,0,0,0.06)` | 下拉菜单、Popover |
| `shadow-lg` | `0 16px 48px rgba(0,0,0,0.12)` | 弹窗、抽屉 |

## 7. 布局

| 场景 | 内容最大宽度 | 说明 |
|---|---|---|
| 营销页 | 1200px | 可局部全宽 |
| 店铺页 | 1080px | 商品网格 3 列 → 平板 2 列 → 手机 1 列 |
| 商品详情 | 1080px | 左图（60%）右信息（40%），手机上下排列 |
| 结算页 | 480px | 单列居中，减少干扰 |
| 后台 | 全宽 | 左侧导航 240px（可折叠为 64px），内容区内边距 32px |

断点：`sm 640 / md 768 / lg 1024 / xl 1280`。移动端优先编写。

## 8. 组件规范

### 8.1 按钮

| 类型 | 样式 | 用途 |
|---|---|---|
| Primary | 近黑底白字（暗色模式反转） | 每个区域最多 1 个：购买、保存、发布 |
| Secondary | 白底 + 边框 | 次要操作：取消、预览 |
| Ghost | 透明底，hover 显示 `--muted` | 工具栏、表格行内操作 |
| Danger | `--danger` 底白字 | 删除、退款，必须二次确认 |
| Link | 品牌色文字，hover 下划线 | 文本内链接 |

尺寸：`sm 32px / md 36px / lg 44px`（高度）。买家页的购买按钮用 `lg` 且移动端全宽。

状态（全部必须实现）：
- **hover**：背景加深或变浅 5%，过渡 150ms
- **active**：`scale(0.98)`
- **focus-visible**：2px 品牌色焦点环 + 2px 偏移
- **disabled**：50% 透明度，`cursor-not-allowed`
- **loading**：显示旋转图标 + 文案保留（如“支付中…”），同时禁止重复点击

### 8.2 输入框
- 高度 36px，`radius-md`，1px 边框。
- focus：边框变品牌色 + 3px 品牌色 15% 透明度外发光。
- 错误：边框 `--danger`，下方 12px 红色错误文字（说明原因和解决方法）。
- label 在上方（14px / 500），辅助说明在下方（12px / `--text-tertiary`）。
- 必填项不用红色星号堆砌，改为在可选项后标注“（可选）”。

### 8.3 卡片
- 白底 + 1px 边框 + `radius-lg`，默认无阴影。
- 可点击卡片：hover 时边框加深 + `shadow-sm` + 上移 2px（200ms）。

### 8.4 商品卡片（店铺页）
- 封面 4:3 或 16:9（同一店铺统一），`radius-lg`，hover 时图片放大 1.03 倍。
- 标题最多 2 行，超出省略。
- 价格使用 `tabular-nums`，免费商品显示“免费”。
- 不在卡片上放购买按钮，点击整卡进入详情。

### 8.5 表格（后台）
- 行高 48px，表头 `--surface` 底色 + 12px / 500 / `--text-tertiary`。
- 只保留横向分割线，不画竖线。
- 行 hover 显示 `--muted` 背景。
- 金额右对齐、等宽数字；状态使用标签组件。
- 行内操作放在最右侧，用 Ghost 按钮或“更多”菜单。

### 8.6 标签 / 状态徽标
- 高度 22px，`radius-sm`，12px 字号，功能色 10% 底 + 原色字。
- 订单状态映射：待支付 = warning，已支付 = info，已交付 = success，已退款 / 已关闭 = 中性灰。

### 8.7 弹窗 / 抽屉
- 遮罩 `rgba(0,0,0,0.4)` + `backdrop-blur-sm`。
- 弹窗宽度 `sm 400 / md 560 / lg 720`，`radius-lg`，`shadow-lg`。
- 表单类编辑优先用右侧抽屉，确认类操作用弹窗。
- 危险操作的确认弹窗需写明后果，例如“删除后买家将无法再下载该文件”。

### 8.8 消息反馈
- 轻提示（Toast）：右下角（移动端顶部），3 秒自动消失，使用 sonner。
- 页面级错误：页面顶部横幅（Alert）。
- **禁止**使用浏览器原生 `alert()` / `confirm()`。

## 9. 页面状态（每个页面和组件都必须设计）

| 状态 | 规范 |
|---|---|
| 加载中 | 骨架屏（Skeleton），形状与真实内容一致；**禁止**全屏转圈 |
| 空状态 | 线性插图或图标 + 一句说明 + 引导按钮，例如“还没有商品，[上架第一个商品]” |
| 错误 | 说明发生了什么 + 用户能做什么 + 重试按钮 |
| 无权限 | 说明原因 + 返回入口 |
| 部分成功 | 例如批量导入卡密时，明确列出成功和失败的条数及失败原因 |
| 离线 / 网络错误 | Toast 提示，并保留用户已输入的内容 |

## 10. 动效

| 类型 | 时长 | 缓动 |
|---|---|---|
| 颜色、边框变化 | 150ms | `ease-out` |
| 位移、缩放（hover） | 200ms | `ease-out` |
| 弹窗、抽屉进出 | 250ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 营销页滚动入场 | 500～800ms | `cubic-bezier(0.16, 1, 0.3, 1)` |

规则：
- 场景 C（后台）只允许状态过渡类动效，不做入场动画。
- 必须支持 `prefers-reduced-motion`，用户关闭动效时只保留透明度变化。
- 只对 `transform` 和 `opacity` 做动画，避免触发重排。

## 11. 图标与图片

- 图标统一使用 **Lucide**，线宽 1.5，尺寸 16（正文）/ 20（按钮、导航）/ 24（空状态）。
- **禁止**使用 emoji 代替图标。
- 图片必须设定宽高比，加载前显示 `--muted` 占位，使用 Next.js `<Image>` 懒加载。
- 用户上传的封面统一裁剪到规定比例。
- 开发阶段的示例数据使用真实感的商品名和图片，**禁止**使用“测试商品1”和 Lorem ipsum。

---

## 12. 文案

- 语气：简洁、友好、专业，用“你”而不是“您”（后台和店铺统一）。
- 按钮用“动词 + 名词”：“上架商品”“复制链接”，不用“确定”“提交”这类空泛文案。
- 错误文案说明原因和解决方法：❌“操作失败” ✅“文件超过 200MB，请压缩后重新上传”。
- 金额统一格式：`¥ 29.90`，后台统计可用 `¥ 1.2 万`。
- 时间：24 小时内显示相对时间（“3 分钟前”），超过则显示 `2026-10-01 18:04`。

---

## 13. 无障碍（Accessibility）

- 文字与背景对比度 ≥ 4.5:1（大字号 ≥ 3:1）。
- 所有交互元素可通过键盘操作，并有可见的焦点状态。
- 图标按钮必须有 `aria-label`。
- 点击区域移动端 ≥ 44 × 44px。

---

## 14. 禁止清单（AI 生成代码时重点检查）

- ❌ 渐变背景、渐变按钮、渐变文字（场景 A 经评审的主视觉除外）
- ❌ 写死的颜色值，以及本规范之外的字号、间距、圆角
- ❌ 同一区域出现两个及以上 Primary 按钮
- ❌ emoji 当图标
- ❌ 大面积使用品牌色
- ❌ 粗于 600 的字重
- ❌ 卡片同时使用粗边框和重阴影
- ❌ 居中对齐的长段落（超过 2 行的文字左对齐）
- ❌ 没有 loading、空状态、错误状态的页面
- ❌ 浏览器原生弹窗

## 15. AI 开发使用说明

给 AI 下达 UI 任务时，使用以下模板：

```
请先阅读 docs/design-system.md，严格遵守其中的规范。
页面场景：[A 营销 / B 店铺 / C 后台]
参考：[截图或网址]
页面结构：[列出区块]
需要的状态：加载 / 空 / 错误 / [其他]
完成后对照「禁止清单」自查，并在浏览器中截图检查桌面端和移动端效果。
```

## 16. 代码约定

- 颜色、字号、圆角、阴影只能使用 `globals.css` 中定义的语义类名，例如 `bg-brand`、`text-text-secondary`、`text-body`、`rounded-lg`、`shadow-md`。
- 字号类名与规范 4.2 一一对应：`text-display`、`text-h1`、`text-h2`、`text-h3`、`text-body-lg`、`text-body`、`text-caption`、`text-price`。
- 合并类名必须使用 `@/lib/utils` 中的 `cn`。它注册了上述自定义字号；直接使用 `cn` 包时，`text-body` 会被误判为颜色类，导致按钮文字颜色被覆盖（ESLint 已禁止直接导入）。
- 通过 `shadcn add` 新增组件后，检查并按本规范调整尺寸、颜色和状态。
