## 1. 项目概述

**项目名称**：MkClou

**一句话定位**：给独立创作者和小商家的虚拟商品店铺 SaaS。**钱直接进你的账户，平台不抽成，店铺有品牌感。**

**核心功能**：商家几分钟开一家店，上架文件、卡密、链接、授权码等虚拟商品；买家付款后系统自动交付；平台提供防盗版、营销工具和数据分析。

---

## 2. 背景与机会

详细分析见 [竞品分析](./competitive-analysis.md)。核心结论：

1. **抽成高**：国内虚拟商品和知识付费平台抽成普遍在 6%～20%（知识星球 20%、小报童约 15%）。
2. **资金安全焦虑**：主流平台代收货款后再提现，存在资金冻结、平台停运风险（面包多曾出现域名被停止解析，Gumroad 被大量投诉资金冻结）。同时，平台代收再转付在国内属于“二清”，有合规风险。
3. **店铺缺少品牌感**：现有平台页面千篇一律，开源发卡网风格老旧。
4. **防盗版能力弱**：国内平台防盗手段有限。
5. **独立开发者缺工具**：国内几乎没有类似 Lemon Squeezy 的 License Key 管理和验证 API。

**机会**：参考海外 Payhip 的“资金直连 + 订阅收费”模式，结合 Lemon Squeezy 的开发者能力，做一款适合国内的产品。

## 3. 目标用户

### 3.1 用户画像

| 画像 | 典型身份 | 卖什么 | 核心诉求 |
|---|---|---|---|
| **A. 独立开发者**（核心） | 写小工具、插件、App 的程序员 | 软件授权码、源码、插件、AI 提示词包、Agent 技能包 | 授权码自动发放与验证、API / Webhook、防止破解分享 |
| **B. 设计师 / 创作者**（核心） | 设计师、插画师、摄影师 | 设计模板、素材、字体、预设、笔刷、Notion 模板 | 店铺好看、防盗图、自动交付 |
| **C. 知识创作者** | 博主、讲师、考研 / 考证达人 | 电子书、资料包、笔记、录播课程链接 | 低抽成、PDF 防扩散、优惠码推广 |
| **D. 卡密小商家** | 游戏点卡、会员兑换码经销 | 卡密、兑换码 | 批量导入、防超卖、库存预警、稳定安全 |

> MVP 优先服务 **A 和 B**：项目负责人本身是开发者（A 类），可作为第一个真实用户；B 类对“品牌感”最敏感，最能体现产品差异。

### 3.2 用户角色

| 角色 | 说明 |
|---|---|
| 商家 | 开店、上架商品、管理订单、查看数据 |
| 买家 | 在商城浏览、搜索、购买商品；**下单无需注册**（凭邮箱查单），注册后可收藏商品、在个人中心查看订单 |
| 平台管理员 | 商家审核、商品内容审核、平台运营数据 |

## 4. 产品定位与核心价值

### 4.1 定位
**国内版 Payhip + Lemon Squeezy**：资金直连、零抽成、有品牌感、对开发者友好。

### 4.2 核心价值（相对竞品的差异）

| # | 价值 | 说明 |
|---|---|---|
| 1 | **钱是你的** | 商家绑定自己的支付宝 / 微信商户号，买家付款直接进商家账户，平台不经手资金 |
| 2 | **零抽成** | 平台只收套餐订阅费，不从任何一笔交易中抽成 |
| 3 | **店铺有品牌感** | 遵循统一设计规范的高质感模板，支持主题色、Logo、封面定制 |
| 4 | **全自动交付** | 文件、卡密、链接、文本、授权码，付款后秒级交付并发邮件 |
| 5 | **防盗版** | 签名下载链接、下载次数限制、PDF 买家水印、隐形水印 |
| 6 | **开发者友好** | License Key 验证 API、Webhook、嵌入式购买按钮 |

### 4.3 不做什么
- ❌ 不做实物商品（无物流、库存、售后发货）
- ❌ 不做内容社区和流量市场
- ❌ 不做直播、重课程体系
- ❌ **平台不代收货款**

## 5. 商业模式

### 5.1 收费方式
由于资金直连，平台**无法也不应该**从交易中扣款，因此采用**纯订阅制**。

| 套餐 | 价格（草案） | 主要限制与权益 |
|---|---|---|
| 免费版 | ¥0 | 最多 3 个商品；每月 50 单；店铺底部显示“Powered by Clou”；基础交付与防盗 |
| 专业版 | ¥29 / 月（年付 ¥290） | 商品不限；订单不限；去除品牌标识；优惠码、追加销售；PDF 水印；数据分析；Webhook |
| 开发者版 | ¥59 / 月（年付 ¥590） | 专业版全部功能 + License Key 验证 API + 嵌入式按钮 + 自定义域名 |

> 定价为草案，需在用户访谈中验证。参考：Payhip 付费套餐 $29 / $99 每月；小鹅通年费数千元起。

### 5.2 盈亏测算（粗略）
- 一台 4 核 8G 云服务器 + 对象存储 + 域名，约 ¥300～500 / 月
- 约 15 个专业版付费商家即可覆盖基础成本

### 5.3 平台自身收款
平台收取商家的订阅费时，MkClou 是收款方，需要以个体工商户或公司主体开通支付宝 / 微信支付。开发阶段使用**支付宝沙箱**。

## 6. 版本范围

### 6.1 MVP（V1.0）——跑通“开店 → 上架 → 购买 → 交付”闭环

**商家端**
- 注册 / 登录（邮箱 + 密码，邮箱验证）
- 创建店铺：名称、Logo、简介、主题色、店铺链接（`mkclou.xxx/s/店铺名`）
- 配置收款：绑定支付宝商户信息（开发期为沙箱）
- 商品管理：上架、编辑、下架；交付类型支持 **文件 / 卡密 / 链接 / 文本**
- 卡密批量导入、库存显示
- 订单列表、订单详情、手动补发
- 基础数据：今日 / 本月销售额、订单数

**买家端**
- 店铺首页、商品详情页
- 填写邮箱下单、支付宝支付
- 支付成功页直接展示交付内容 + 交付邮件
- 凭邮箱 + 验证码查询历史订单

**平台端**
- 商家列表、封禁
- 商品内容审核（举报 + 人工下架）

**系统能力**
- 订单状态机、超时自动关单
- 支付回调验签与幂等
- 卡密防超卖
- 私有文件存储 + 签名下载链接 + 下载次数限制
- 接口限流

### 6.2 V1.1——增强转化与开发者能力
- 优惠码、捆绑销售、追加销售
- PDF 买家水印
- License Key 生成 + 验证 API
- Webhook
- 嵌入式购买按钮
- 数据分析：访问 → 下单 → 支付转化漏斗、来源追踪（UTM）
- 订阅套餐与平台收费

### 6.3 V2——差异化护城河
- 会员订阅商品（按月解锁内容）
- AI 辅助：生成商品描述、基于商品 FAQ 的 AI 买家答疑
- 图片隐形水印
- 分销联盟（设佣金上限，避免内卷）
- 自定义域名
- 微信支付；探索与持牌机构合作的分账方案，降低个人商家的收款门槛

## 9. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| **支付资质门槛**：支付宝 / 微信网站支付需要个体户或企业资质，个人商家难以开通 | 高 | 开发期使用沙箱；入驻引导中说明个体户办理流程；V2 探索持牌机构分账合作 |
| **自营商品合规**：转售第三方平台账号（如 AI 工具账号）通常违反该平台服务条款，可能被封号、引发售后纠纷，并导致支付渠道风控 | 高 | 自营商品优先选择自己制作的内容（教程、提示词包、模板、工具授权码）；平台规则中将“第三方账号转售”列入禁售或高风险类目 |
| **违规内容**：盗版资源、违法内容被上架 | 高 | 用户协议明确禁售范围；举报 + 人工审核；关键词过滤；保留封禁能力 |
| **ICP 备案**：使用境内服务器需备案，耗时 1～3 周 | 中 | 提前准备；备案期间可先用境外服务器演示 |
| **个人信息合规**：买家邮箱等属于个人信息 | 中 | 隐私政策、最小化收集、敏感字段加密存储 |
| **冷启动没有用户** | 中 | 负责人自己作为第一个商家；从开发者社区（V2EX、LINUX DO、即刻、小红书）邀请种子用户 |
| **个人精力不足、项目烂尾** | 高 | 严格控制 MVP 范围；每两周一个可演示的成果；文档轻量迭代 |
| **竞品跟进** | 低 | 作为求职项目，重点在技术深度和完整度，不以市场份额为目标 |
