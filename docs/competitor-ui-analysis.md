## 1. Gumroad

### 1.1 发现页（gumroad.com/discover）
**布局**
```
┌───────────────────────────────────────────────────────┐
│ Logo  [ 搜索商品………………………… ]        登录  [开始售卖]    │
│ 全部 · 绘画 · 3D · 设计 · 音乐 · 影视 · 软件开发 · … 更多 ▾ │  ← 分类横向导航
├───────────────────────────────────────────────────────┤
│ 精选商品                                    ← 1/8 →    │  ← 轮播
│ ┌──────────┬────────┐  ┌──────────┬────────┐          │
│ │ 封面大图  │标题     │  │ 封面大图  │标题     │          │
│ │          │简介     │  │          │简介     │          │
│ │          │卖家     │  │          │卖家     │          │
│ │ [价格签]  │  ★ 3.5 │  │ [价格签]  │  ★ 4.2 │          │
│ └──────────┴────────┘  └──────────┴────────┘          │
├───────────────────────────────────────────────────────┤
│ 市场            [热门] [畅销] [新品]                     │
│ ┌筛选──┐  ┌商品┐ ┌商品┐ ┌商品┐                          │
│ │标签  │  │    │ │    │ │    │                          │
│ │价格  │  └────┘ └────┘ └────┘                          │
│ └─────┘                                               │
└───────────────────────────────────────────────────────┘
```

**特点**
- 深色背景 + 高饱和粉色价格标签（斜角“价签”造型），品牌辨识度高
- 订阅类商品价格直接显示周期，如“$8 a month”
- 评分（星级 + 评价数）直接展示在卡片上，建立信任

### 1.2 商品详情页
**布局**：上方大图，下方左右两栏。
```
┌───────────────────────────────────────────────┐
│               商品封面 / 预览图（宽幅）            │
├──────────────────────────────┬────────────────┤
│ 标题                          │ [加入购物车]     │
│ 现价 $29.99  原价 $39.98（划线）│ 已经买过？        │
│ 卖家头像·名称   ★★★☆ 4 条评价  │ 获取下载链接 →    │
│ ───────────────               │ 一句话卖点        │
│ 捆绑包包含：                    │ [♡ 加入心愿单] [分享]│
│  · 子商品 A  $19.99 →          │ ─────────────── │
│  · 子商品 B  $19.99 →          │ 评分 3.5         │
│ ───────────────               │ 5★ ████ 50%      │
│ 商品描述（长文，可“阅读更多”）     │ 3★ ██   25%      │
│                               │ 1★ ██   25%      │
│                               │ 评价列表           │
│                               │ “已验证买家”徽标    │
│                               │ 卖家综合评分：4.5    │
└──────────────────────────────┴────────────────┘
（滚动后顶部出现吸顶的“商品信息条”：标题 + 价格 + 购买按钮）
```

**值得学习**
| 设计 | 作用 |
|---|---|
| 吸顶商品信息条 | 长描述页面中随时可以购买，提升转化 |
| 原价划线 + 现价 | 制造优惠感 |
| 捆绑包内容清单 | 子商品可单独点击查看，明确“买一送一”的价值 |
| “已经买过？获取下载链接” | 买家免注册，也能找回已购商品 |
| 评分分布直方图 + 已验证买家 | 建立信任，评价只能由真实买家发表 |
| 卖家跨商品综合评分 | 新商品也能借助卖家口碑 |
| 心愿单、分享 | 暂时不买的用户也能留存 |

**不足**
- 卖家写的描述大量使用 emoji 和全大写标题，排版质量依赖卖家自己，页面观感参差不齐
- 页面信息较多，首屏只看到一张大图，看不到价格和购买按钮（需要滚动）

### 1.3 结账页
```
┌──────────────────────────────┬──────────────────┐
│ 结账                [继续购物] │                  │
│ ┌────────────────────────┐  │ 邮箱               │
│ │ 封面  商品名      $29.99 │  │ 姓名               │
│ │      卖家  [移除]        │  │ 国家 ▾   邮编       │
│ │ 捆绑包包含：子商品列表      │  │ 支付方式            │
│ │ ○ 作为礼物赠送？          │  │ [ 支付 ]           │
│ └────────────────────────┘  │ reCAPTCHA 说明      │
│ 打赏小费：[不打赏][15%][20%][25%] │                  │
│          [自定义金额]          │                  │
│ 小计 / 合计                    │                  │
└──────────────────────────────┴──────────────────┘
```

**值得学习**
- **购物车**：支持一次购买多个商品
- **作为礼物赠送**：虚拟商品送人是真实需求，对国内节日场景也适用
- **打赏小费**：卖家可开启，让买家额外支持
- 支付按钮在信息填完前保持禁用

## 2. Lemon Squeezy

### 2.1 官网（营销页，场景 A 参考）
**布局**：顶部公告条 → 导航 → 左文右图 Hero（大标题 + 一句话 + 一个按钮，右侧倾斜的后台截图）→ 信任背书（客户 Logo）→ 六宫格卖点 → 分模块介绍（电商 / 营销 / 报表 / 开发者，每块 6 个特性，编号 E/1、M/1…）

**视觉特点**
- 品牌色大面积使用（紫底），配黄色公告条，大胆但只用在营销页
- 超大号细字重标题，字距紧凑
- **用产品界面截图当主视觉**，直接展示“后台长什么样”

**值得学习的功能点**（来自官网）
| 功能 | 说明 |
|---|---|
| 签名下载链接 + 限流 | 下载链接带签名并限速，防滥用 |
| License Key 管理 | 售后自动发放，可停用、重新发放 |
| 无代码结账链接 + 嵌入 | 任何网站都可以嵌入结账 |
| 随心付（Pay what you want） | 买家自己出价，适合引流品 |
| 免费引流品（Lead magnet） | 免费领取以收集邮箱 |
| 捆绑销售 + 追加销售 | 提高客单价 |
| 弃单挽回 | 用户下单未支付时自动提醒 |
| 客户分群 | 按购买行为划分客户 |
| 实时营收、平均客单价、退款统计 | 数据看板 |

## 3. 爱发电

### 3.1 首页
- 简洁白底 + 紫色品牌色，大标题 + 一句话 + 两个按钮
- **问题**：部分图标字体加载失败，显示为方框；首页“创作者展示”区域加载为空白，第一印象不好

```
│ (头像) 名称                          [¥ 为TA发电]  │

└──────────────┴────────────────────────────────┘
```

### 3.4 赞助方案页
- 方案以**纵向大卡片**排列：商品图 + “限时特价”标签 + 名称 + 现价 / 划线原价 + 说明 + 底部购买按钮
- 实际案例：一位独立开发者在这里卖自家产品的**年度 / 季度会员兑换码**，说明里写着“购买后收到兑换码，请到官网会员页面兑换”

**启示**
- 独立开发者确实在用“兑换码”方式卖自家软件会员，但**买家需要手动复制码、跳转到另一个网站兑换**，体验割裂
- MkClou 的 License Key 验证 API 可以让开发者的软件**自动校验激活**，或者通过 Webhook 在付款后直接为买家开通，无需手动兑换
- 方案卡片单列排列，桌面端右侧大片留白，空间利用率低

## 4. 面包多

### 4.1 首页
- 黄色品牌色，扁平插画风，大标题“你专心创作”式文案 + 两个按钮
- 卖点：专属小店（**支持自定义 CSS、布局、背景**）、灵活出售、闪电结算、原创保护、营销组件
- 三步上手说明：创建内容 → 分享链接 → 获得收益
- 创作者证言墙：头像 + 身份 + 证言 + “在售作品数 / 购买人次”

**启示**
- **“三步上手”**降低理解成本，MkClou 官网可以沿用
- 证言卡片附带**真实销售数据**，比纯文字评价更可信
- 证言和数据停留在 2019 年，页脚版权停在 2024 年，**内容长期不更新会削弱信任**
- 自定义 CSS 很灵活，但普通用户不会写，容易把页面改乱。MkClou 的做法是**提供受控的主题配置**（主题色、Logo、封面、布局模板），保证不管怎么配置都好看

## 5. 综合结论：MkClou 页面设计决策

### 5.1 买家侧

| 页面 | 参考 | MkClou 的优化 |
|---|---|---|
| 店铺首页 | 爱发电创作者主页 | 封面横幅 + 头像 + 简介，**下方直接是商品网格**（而不是动态信息流），首屏就能看到商品 |
| 商品详情 | Gumroad | 采用左图右信息布局，**首屏即可看到价格和购买按钮**；保留吸顶购买条、划线价、捆绑包清单、评分直方图、已验证买家 |
| 商品描述 | Gumroad | 提供**结构化描述模板**（简介 / 包含内容 / 适用对象 / 常见问题），由平台统一排版，避免卖家自由排版导致页面杂乱 |
| 结账 | Gumroad | 单页结账，只需填写邮箱；保留“送给朋友”；去掉国家、邮编等国内用不到的字段；支持支付宝扫码和手机唤起 |
| 已购找回 | Gumroad | “已经买过？”入口 → 邮箱验证码 → 查看全部已购商品 |
| 交付页 | — | 支付成功后直接展示交付内容（文件下载 / 卡密一键复制 / 授权码），并说明“已发送到邮箱” |

### 5.2 商家侧
| 功能 | 参考 | MkClou 的优化 |
|---|---|---|
| 店铺装修 | 面包多自定义 CSS | 受控主题配置 + 实时预览，**任何配置都符合设计规范** |
| 商品类型 | 爱发电方案卡片 | 交付方式统一为一个选择器：文件 / 卡密 / 链接 / 文本 / 授权码 |
| 软件会员 | 爱发电兑换码案例 | License Key + 验证 API + Webhook，免去手动兑换 |
| 营销 | Lemon Squeezy | 优惠码、捆绑、追加销售、随心付、免费引流品、弃单挽回（V1.1～V2） |
| 数据 | Lemon Squeezy | 营收、订单数、客单价、转化漏斗、来源 |

### 5.3 营销官网
- Hero：左侧大标题 + 一句话 + 主按钮，右侧**产品真实界面截图**（参考 Lemon Squeezy）
- “三步开店”说明（参考面包多）
- 竞品费率对比表：直观展示“零抽成”优势
- 真实商家案例 + 销售数据（随时更新，避免面包多的内容过期问题）
- 可在此页面使用 Awwwards 风格的滚动动效（设计规范场景 A）
